# VoiceRAG demo videos

These short, synthetic-voice MP4 clips are ready to upload in VoiceRAG:

- `rag-basics.mp4` — retrieval augmented generation
- `raft-consensus.mp4` — Raft leader election and log replication
- `backpropagation.mp4` — neural network training with gradients

The matching WAV files are the generated narration sources. The app accepts each MP4 from its upload screen and sends its audio to the configured AssemblyAI transcription service.
